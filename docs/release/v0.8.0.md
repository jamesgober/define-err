# define-err v0.8.0 - Alpha

**Tried on real crates.** v0.8.0 is what the first migrations taught. Five crates in four repositories moved from thiserror to define-err 0.7.0, as draft pull requests their owners merge. Every message, `Debug` output, and `source()` came out byte-identical, and a crate published at 1.0 passed `cargo semver-checks` with nothing to bump. Along the way they found three things to fix, and this release fixes them.

## What is define-err?

<strong>define-err</strong> is how a Rust library says what its errors are, with no proc macro, no build dependency, and no run-time cost. It is `no_std` and has no dependencies.

```rust
use define_err::define_errors;

define_errors! {
    pub enum PageError {
        NotFound { page: u64 } => "page {page} not found",
        Io(#[from] source: std::io::Error) => "page file i/o failed",
    }
}
```

## What's in 0.8.0

- **Paths, as thiserror shows them.** A `PathBuf`, `Path`, or `&Path` field in a message now formats through `display()`. A thiserror message like `"file not found: {0}"` on a `PathBuf` can be kept as written; it used to need `path.display()` spelled out. Every other field formats exactly as before, and nothing changes at run time. It costs at build time: a 500-variant enum rebuilds about 11% slower, measured and published in `docs/PERFORMANCE.md`.
- **One error for one mistake.** A code without its `help` text reports that, once. Two of them used to report a duplicate code that did not exist.
- **`#[cfg]` on a whole type.** Compiling a type out now compiles out everything generated for it. It used to leave the impls behind and fail to build.
- **Locations without the home directory.** `short_file` cuts a dependency's registry path, which names the user's home directory, down to the crate's own directory, for a sink that logs where an error came from.
- **A migration guide that knows more.** `docs/MIGRATION.md` now covers path fields, what implementing `ErrorInfo` means for a crate past 1.0, a type that already has its own `code()`, and the `help` every code needs.

## For the attribute front end

Generated code changed: the `Display` arm of a plain message rebinds its fields first, and a type with `#[cfg]` gets its impls in one `const _` block. `docs/GENERATED-CODE.md` has every detail.
