# define-err v0.5.0 - Facade

**Feature complete: a reporting facade any crate can call.** v0.5.0 adds the verbs a library uses to say something went wrong and the one reporter an application installs to hear it, with the `log` crate's write-once design. With nothing installed, a verb is one atomic load. It also adds `ErrorRecord`, an owned and bounded snapshot of an error, and test capture.

## What is define-err?

<strong>define-err</strong> is how a Rust library says what its errors are, with no proc macro, no build dependency, and no run-time cost. It is `no_std` and has no dependencies.

```rust
use define_err::{Event, Reporter};

struct StderrReporter;

impl Reporter for StderrReporter {
    fn receive(&self, event: &Event<'_>) {
        if let Some(message) = event.message() {
            eprintln!("{} {message}", event.severity());
        }
    }
}

static REPORTER: StderrReporter = StderrReporter;

fn main() {
    define_err::set_reporter(&REPORTER).expect("install the reporter first thing in main");
    define_err::warn("cache file is stale, rebuilding");  // once per call site
}
```

## What's in 0.5.0

- **The verbs.** `report`, `notice`, `warn`, `trigger`, `deprecated`, and `soft`, with `_with` forms and format-string macros. Every one records the caller's file, line, and column, and a `#[track_caller]` helper reports where it was called. Reporting never changes control flow.
- **A write-once reporter.** `set_reporter` works once, and a later call is told the file and line of the one that won, so a dependency cannot quietly install itself first. `reporter_installed_at` answers the same question for audits.
- **Once per call site.** A warning in a loop reaches the reporter one time: an exact flag behind `warn!`, a lock-free 512-site table behind `warn()`, and a counter when the table overflows, so a warning is never lost. A warning that could not be delivered keeps its one delivery for later.
- **Filters.** A warn mode (`Once`, `Always`, `Ignore`, and `Error`, which makes `soft` fail in a strict deployment), a minimum severity, and a kinds mask, applied before anything is formatted.
- **Guards.** With `std`, a verb called from inside a reporter is dropped and counted, and a panic inside one is caught and counted, a panicking payload drop included. Without `std`, `docs/FACADE.md` states the contract.
- **`ErrorRecord`.** An owned, `Send + Sync + Clone` snapshot for anything that outlives the event. Every part is bounded before the allocation it guards, cuts fall on character boundaries, a `Secret<T>` field stays `[redacted]`, and the public message never comes from a `Display`.
- **Test capture.** `testing::capture` returns every event delivered on the calling thread, so tests running in parallel stay apart. If someone else's reporter is installed it refuses to run, so an empty list can never pass as the real one.
- **`#[cfg]`** on variants and on plain fields, followed by every generated arm, conversion, catalog entry, and check.
- **Public messages through `&dyn Error`.** The identity probe now carries a variant's `#[public]` text, and each probe takes exactly the bytes it needs.
- **Every target.** On a target without compare-and-swap, the verbs compile to nothing and library code that reports builds unchanged; a `no_std` example crate proves it on four bare-metal targets in CI.
- **Tested hard.** Loom models every interleaving of the slot, settings, site flags, and table; Miri runs the suite over the crate's one module of `unsafe` code; a counting allocator checks every verb allocates nothing in every state; a new fuzz target drives the record with arbitrary chains; edge cases E-65 to E-95 are covered.
